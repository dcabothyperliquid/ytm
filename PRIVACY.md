# Privacy Policy - Localmatchlive

Last updated: 14 November 2026

Localmatchlive is a private tool used only by its owner to manage the owner's own YouTube channel (go live, set the live title/description, end a live stream and upload highlight videos).

**What the app accesses:** only the owner's own YouTube channel, through the YouTube Data API, after the owner's explicit consent.

**What we collect:** nothing from any other person. The app has no public users, no sign-up, no analytics and no advertising.

**How data is stored:** the access credentials are kept only as encrypted GitHub Actions secrets of the owner's private account. No data is sold, shared or disclosed to any third party.

**Revoking access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.
